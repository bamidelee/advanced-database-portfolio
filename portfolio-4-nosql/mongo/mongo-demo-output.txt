stored compressed. That is why there are far fewer buckets than points,
and why each point costs only a few bytes on disk.

 4. Driver reports arrival: an atomic update inside one document
======================================================================
The positional operator $ targets the attempt matching trip_id. The status
change and the new timeline entry are applied together: MongoDB guarantees
that all changes to a single document are atomic.

{
  delivery: 71385,
  trip: 69831,
  matched: 1,
  modified: 1
}
[
  {
    status: 'arrived',
    timeline: [
      {
        status: 'assigned',
        at: ISODate('2026-10-18T09:13:41.073Z')

 5. Flexible schema: optional data only some deliveries have
======================================================================
Some vendors test water quality on delivery. In PostgreSQL this needs a new
table or nullable columns and a migration. Here the reading is simply added
to the deliveries that have one.

{
  water_quality: {
    tds_ppm: 180,
    chloride_mg_per_l: 95,
    ph: 7.2,
    tested_at: ISODate('2026-10-20T10:00:23.344Z')
  }
}
{
  deliveries_with_water_test: 1,
  deliveries_with_access_notes: 25320,
  deliveries_with_refunds: 1344
}
